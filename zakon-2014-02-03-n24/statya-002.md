# Статья 2.
Настоящий Закон вступает в силу со дня официального опубликования.
Рекомендовать Президенту Кыргызской Республики принять меры, вытекающие из настоящего Закона.
Правительству Кыргызской Республики:
- привести свои нормативные правовые акты в соответствие с настоящим Законом;
- инициировать проекты законов Кыргызской Республики, вытекающих из настоящего Закона.

Кыргызской Республики
