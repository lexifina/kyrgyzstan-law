# Статья 67-1. Порядок прохождения коррекционной программы по изменению насильственного поведения
1. Суд, вынесший приговор, содержащий требование о прохождении коррекционной программы по изменению насильственного поведения, после вступления приговора в законную силу направляет его копию для исполнения в учреждения, исполняющие наказания и принудительные меры уголовно-правового воздействия, связанные с изоляцией от общества.
2. Порядок проведения коррекционной программы по изменению насильственного поведения устанавливается Кабинетом Министров Кыргызской Республики.
