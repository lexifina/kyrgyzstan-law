# Статья 51. Обоснованный риск
1. Не является преступлением причинение вреда правоохраняемым интересам при обоснованном риске для достижения общественно полезной цели.
2. Риск признается обоснованным, если указанная цель не могла быть достигнута не связанными с риском действиями (бездействием) и лицо, допустившее риск, предприняло достаточные меры для предотвращения вреда охраняемым настоящим Кодексом интересам.
3. Риск не признается обоснованным, если он заведомо был сопряжен с угрозой гибели людей, экологической катастрофы либо наступления иных тяжких последствий.
