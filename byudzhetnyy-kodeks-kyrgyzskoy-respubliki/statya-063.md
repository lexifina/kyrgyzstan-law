# Статья 63. Государственные гарантии
1. Государственная гарантия предоставляется уполномоченным государственным органом по решению Кабинета Министров по согласованию с Жогорку Кенешем.
Порядок предоставления государственной гарантии определяется Кабинетом Министров.
2. Государственные гарантии, не предусмотренные настоящим Кодексом, регулируются законодательством об инвестициях.
