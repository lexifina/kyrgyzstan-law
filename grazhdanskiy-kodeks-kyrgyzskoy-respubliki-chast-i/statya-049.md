# Статья 49. Банковский сертификат
Банковским сертификатом признается письменное свидетельство банка о вкладе денежных средств, удостоверяющее право вкладчика на получение по истечении установленного срока суммы вклада, процентов либо иной платы по нему в любом учреждении данного банка.
Банковские сертификаты являются именными.
