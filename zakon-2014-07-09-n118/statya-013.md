# Статья 13. Методики выполнения измерений
1. При выполнении поверки средств измерений методики выполнения измерений являются обязательными для применения.
2. Вне сферы государственного регулирования, в добровольном порядке, могут применяться аттестованные методики выполнения измерений, а также разработанные юридическими лицами и индивидуальными предпринимателями.
