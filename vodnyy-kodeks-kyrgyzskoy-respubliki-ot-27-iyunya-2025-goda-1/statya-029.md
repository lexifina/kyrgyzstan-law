# Статья 29. Приоритеты по водопользованию
До одобрения бассейнового плана, которым устанавливается обоснованный порядок приоритетов для целей водопользования, распределение воды, включая подземные воды, осуществляется с учетом следующих приоритетов:
1) использование воды для питьевых и хозяйственно-бытовых нужд;
2) использование воды для целей орошения и водопоя скота;
3) использование воды для целей выработки электроэнергии, включая возобновляемую энергию;
4) использование воды для промышленности, включая горную и аграрную промышленность;
5) использование воды для целей рыболовства и рыбоводства;
6) использование воды для спортивных и оздоровительных целей;
7) использование воды для других целей.
