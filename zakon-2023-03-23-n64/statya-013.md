# Статья 13. Деятельность риелтора по предоставлению информационных и консультационных услуг, услуг по изучению конъюнктуры рынка, иных возмездных услуг, сопутствующих гражданскому обороту недвижимого имущества
Деятельностью риелтора по предоставлению информационных и консультационных услуг, услуг по изучению конъюнктуры рынка, иных возмездных услуг, сопутствующих гражданскому обороту недвижимого имущества, признается обеспечение потребителя информацией об объектах недвижимого имущества, иной необходимой для заключения сделки информацией, оказание услуг по изучению конъюнктуры рынка, иных возмездных услуг, сопутствующих гражданскому обороту недвижимого имущества.
