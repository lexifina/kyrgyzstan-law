# Статья 37. Порядок и сроки принятия решений по вопросам гражданства Кыргызской Республики
1. Рассмотрение заявлений по вопросам гражданства Кыргызской Республики и принятие по ним решений по ходатайствам в общем порядке осуществляются в срок до одного года со дня подачи ходатайства с приложением надлежаще оформленных документов.
2. Рассмотрение заявлений лиц, подающих ходатайства на получение гражданства или выход из гражданства Кыргызской Республики в упрощенном порядке и принятие по ним решений осуществляются Президентом Кыргызской Республики в срок до шести месяцев со дня подачи ходатайства с приложением надлежаще оформленных документов.
3. Изменение в гражданстве наступает с момента издания указа Президента Кыргызской Республики.
Лица, указанные в статье 26 настоящего Закона, утрачивают гражданство Кыргызской Республики в соответствии с решением, принимаемым Президентом Кыргызской Республики.
4. Повторные заявления по вопросам гражданства рассматриваются по истечении одного года после принятия предыдущего решения по этому вопросу. В случае возникновения существенных для дела обстоятельств, которые не были и не могли быть известны заявителю, повторное заявление может быть рассмотрено и ранее.
