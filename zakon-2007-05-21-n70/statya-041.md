# Статья 41. Обжалование решений по вопросам гражданства
1. Решения по вопросам гражданства могут быть обжалованы в судебном порядке.
2. Жалоба может быть подана в течение шести месяцев со дня принятия соответствующего решения. Пропущенный по уважительной причине срок обжалования решения по вопросам гражданства может быть восстановлен в судебном порядке.
