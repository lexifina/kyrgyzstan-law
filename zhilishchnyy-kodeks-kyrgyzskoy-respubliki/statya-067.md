# Статья 67. Приобретение жилых помещений путем ипотечного жилищного кредитования
Граждане вправе приобретать жилое помещение путем осуществления ипотечного кредитования. Порядок заключения договоров ипотеки, обеспечивающей целевые кредитные договоры для приобретения жилых помещений, регулируется гражданским законодательством.
