# Статья 257. Орган, возглавляющий забастовку
1. Забастовку возглавляет представительный орган работников. Орган, возглавляющий забастовку, имеет право созывать собрания (конференции) работников, получать от работодателя информацию по вопросам, затрагивающим интересы работников, привлекать специалистов для подготовки заключений по спорным вопросам.
2. Орган, возглавляющий забастовку, имеет право приостановить забастовку. Для возобновления забастовки не требуется повторного рассмотрения спора примирительной комиссией. Работодатель должен быть предупрежден о возобновлении забастовки не позднее чем за 3 рабочих дня
