# Статья 105. Оплата труда при изготовлении продукции, оказавшейся браком
1. Брак не по вине работника оплачивается наравне с годными изделиями.
2. Полный брак по вине работника оплате не подлежит.
3. Частичный брак по вине работника оплачивается по пониженным расценкам в зависимости от степени годности продукции.
