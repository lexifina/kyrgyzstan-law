# Статья 127. Права и обязанности учеников по окончании ученичества
1. Лицам, успешно завершившим ученичество по договору, в соответствии с которым они проходили обучение, при заключении трудового договора испытательный срок не устанавливается.
2. Если ученик по окончании ученичества без уважительных причин не выполняет свои обязательства по договору, в том числе не приступает к работе, он по требованию работодателя возвращает ему полученную за время ученичества стипендию, а также возмещает другие понесенные работодателем расходы в связи с ученичеством.
