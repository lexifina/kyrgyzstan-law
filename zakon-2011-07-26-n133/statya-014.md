# Статья 14. Социальные службы для пожилых граждан
1. Для оказания практической социальной помощи пожилым гражданам государственными органами совместно с органами местного самоуправления, общественными организациями и объединениями пожилых граждан поддерживаются социальные службы для пожилых граждан.
2. Социальные службы для пожилых граждан оказывают информационную, психологическую, медицинскую и иные формы социальной помощи, реализуют необходимые меры с целью предупреждения негативных явлений по отношению к пожилым гражданам (правонарушений, в том числе жестокого обращения с пожилыми гражданами и т.д.), осуществляют социальную опеку отдельных категорий пожилых граждан, занимаются профилактикой наркомании и алкоголизма среди пожилых граждан.
