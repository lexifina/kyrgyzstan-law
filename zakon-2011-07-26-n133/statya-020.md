# Статья 20. Санаторно-курортное лечение пожилых граждан
1. Предприятие (организация) по месту оформления пенсии может предоставлять пожилым гражданам путевки на санаторно-курортное лечение по согласованию с профсоюзным комитетом.
2. В случае реорганизации этих предприятий (организаций) обеспечение данного вида социальной гарантии возлагается на их правопреемников.
