# Статья 15. Службы Гражданской защиты
1. Для выполнения мероприятий по Гражданской защите в мирное и военное время создаются республиканские, областные, районные и городские службы Гражданской защиты.
2. Службы Гражданской защиты предназначены:
1) для выполнения инженерно-технических, медицинских и других специальных мероприятий Гражданской защиты;
2) для подготовки своих сил и средств;
3) для обеспечения действий органов управления и сил Гражданской защиты в ходе проведения аварийно-спасательных и других неотложных работ;
4) для выполнения специальных задач в соответствии с решениями комиссии Гражданской защиты.
3. Решения о создании служб Гражданской защиты, их перечень и положения о них принимаются на соответствующих уровнях Кабинетом Министров Кыргызской Республики, государственными органами, местными государственными администрациями, органами местного самоуправления и руководителями организаций в соответствии с их полномочиями.
