# Статья 13. Имущество уполномоченного органа
Здания, сооружения, транспортные средства, средства связи и другое государственное имущество, необходимые для обеспечения деятельности уполномоченного органа, находятся в оперативном управлении уполномоченного органа, согласно законодательству Кыргызской Республики.
