# Статья 38. Цифровая доступность
1. Государственные и муниципальные услуги, оказываемые в цифровом формате, должны быть доступными для лиц с инвалидностью.
2. Программные приложения для мобильных устройств и компьютеров, интернет-сайты, с помощью которых оказываются услуги населению, должны быть адаптированы под программы чтения с экрана для лиц с инвалидностью.
3. Мобильные приложения коммерческих банков, банкоматы и банковские терминалы должны быть адаптированы для самостоятельного использования лицами с инвалидностью, включая лиц с нарушениями зрения, слуха, опорно-двигательного аппарата, в соответствии с техническими стандартами и принципами универсального дизайна.
