# Статья 2.
Министерству финансов Кыргызской Республики уведомить по дипломатическим каналам японскую сторону о выполнении Кыргызской Республикой внутригосударственных процедур, необходимых для вступления в силу вышеуказанного международного договора, заключенного путем обмена нотами, и Грантового соглашения.
