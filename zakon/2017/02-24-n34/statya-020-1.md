# Статья 20-1. Порядок проведения коррекционной программы по изменению насильственного поведения
1. Органы пробации проводят коррекционные программы по изменению насильственного поведения клиентов пробации, совершивших семейное насилие.
2. Проведение коррекционной программы по изменению насильственного поведения осуществляется в период исполнительной пробации.
3. Порядок проведения коррекционной программы по изменению насильственного поведения устанавливается Кабинетом Министров Кыргызской Республики.
4. Пробационный надзор за клиентами пробации, направленными для прохождения коррекционной программы по изменению насильственного поведения, осуществляется с учетом правил ее прохождения.
