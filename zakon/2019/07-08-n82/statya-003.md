# Статья 3. Субъекты правоотношений в области официальной статистики
Субъектами правоотношений в области официальной статистики являются:
1) Национальный статистический комитет Кыргызской Республики (далее - Национальный статистический комитет);
2) другие производители официальной статистики;
3) респонденты;
4) пользователи официальной статистики;
5) поставщики административных данных;
6) Совет по статистике Кыргызской Республики (далее - Совет по статистике);
7) частные поставщики данных.
