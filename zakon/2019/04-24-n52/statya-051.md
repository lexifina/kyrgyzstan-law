# Статья 51. Ставки таможенных пошлин, налогов, применяемые для исчисления таможенных пошлин, налогов
1. Порядок определения ставок ввозных таможенных пошлин, применяемых для их исчисления, установлен статьей 53 Кодекса.
2. Порядок определения ставок вывозных таможенных пошлин, применяемых для их исчисления, устанавливается Кабинетом Министров Кыргызской Республики.
3. Для исчисления налогов применяются ставки, установленные налоговым законодательством Кыргызской Республики.
