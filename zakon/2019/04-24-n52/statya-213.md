# Статья 213. Основания для исключения из реестра таможенных перевозчиков
Основаниями для исключения таможенного перевозчика из реестра таможенных перевозчиков являются:
1) основания, предусмотренные пунктом 1 статьи 408 Кодекса;
2) иные основания, которые установлены Кабинетом Министров Кыргызской Республики.
