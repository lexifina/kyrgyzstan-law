# Статья 29. Срок военной службы
1. Срок военной службы в календарном исчислении устанавливается:
для военнослужащих срочной военной службы - двенадцать месяцев;
для офицеров, проходящих военную службу по призыву, - двадцать четыре месяца;
для военнослужащих, проходящих военную службу по контракту, - сроки, указанные в положениях о порядке прохождения военной службы.
2. Солдатам, сержантам, отбывающим наказание в дисциплинарных частях, время отбывания наказания в срок срочной военной службы не засчитывается.
3. Руководителю уполномоченного государственного органа, ведающего вопросами обороны, в целях выполнения определенных задач, связанных с прохождением срочной военной службы, предоставляется право оставлять на военной службе военнослужащих срочной военной службы сверх установленного срока, но не более двух месяцев, по ходатайству начальника Генерального штаба Вооруженных Сил, руководителя соответствующего государственного органа, в котором предусмотрена срочная военная служба.
