# Статья 15-1. Осуществление уполномоченным органом по развитию предпринимательства контроля законодательства о проверках
1. На уполномоченный орган по развитию предпринимательства и его соответствующие территориальные подразделения возлагаются функции контроля соблюдения законодательства о проверках уполномоченными органами по всем видам проверок, регулируемых настоящим Законом.
2. Уполномоченный орган по развитию предпринимательства для проведения контроля сотрудничает с организациями, осуществляющими защиту прав и законных интересов субъектов проверки.
