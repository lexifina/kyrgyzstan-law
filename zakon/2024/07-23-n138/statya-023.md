# Статья 23. Порядок предоставления резидентам технопарков информации по вопросам, связанным с развитием технопарков в Кыргызской Республике
1. Информация по вопросам, связанным с развитием технопарков в Кыргызской Республике, может предоставляться резидентам технопарков на основании их заявлений о предоставлении такой информации.
2. Заявления о предоставлении информации по вопросам, связанным с развитием технопарков в Кыргызской Республике, подаются резидентами технопарков в уполномоченный орган.
3. В заявлениях о предоставлении информации по вопросам, связанным с развитием технопарков в Кыргызской Республике, наряду с другими сведениями должны содержаться:
1) перечень сведений, запрашиваемых резидентом технопарка;
2) обоснование необходимости использования информации для осуществления законной деятельности на территории технопарка.
4. Заявления о предоставлении информации по вопросам, связанным с развитием технопарков в Кыргызской Республике, рассматриваются уполномоченным органом в соответствии с законодательством Кыргызской Республики.
