# Статья 85. Свидетельствование подлинности факсимильной подписи лица с ограниченными возможностями здоровья
1. Факсимильная подпись (факсимиле) - специально изготовленный штамп (клише), заменяющий собственноручную подпись лиц с ограниченными возможностями здоровья, которые в силу состояния здоровья не имеют физической возможности самостоятельно совершать собственноручную подпись (нарушения зрения).
2. Лицо с ограниченными возможностями здоровья предоставляет нотариусу изготовленный с помощью технических средств штамп (клише), расписывается им в присутствии нотариуса, после чего нотариус заверяет образец подписи и выдает лицу с ограниченными возможностями здоровья свидетельство о подлинности данного факсимиле.
3. Удостоверенное факсимиле полностью приравнивается по своему юридическому значению к собственноручной подписи.
4. При утере факсимиле и изготовлении нового штампа требуется его повторное нотариальное удостоверение.
