# Статья 11. Деятельность по организации торговли недвижимым имуществом
Деятельностью по организации торговли недвижимым имуществом признается деятельность риелтора по предоставлению участникам рынка недвижимого имущества комплекса услуг, способствующих надлежащему заключению и (или) исполнению сделок, в том числе:
1) услуг по информационному обеспечению участников сделок (предоставление информации об объектах, ценах на них, иной информации);
2) консультационных услуг, услуг по оформлению документов;
3) услуг по надлежащему и безопасному проведению расчетов по сделкам, за исключением услуг, предоставление которых допускается исключительно при наличии лицензии на право осуществления банковской деятельности.
