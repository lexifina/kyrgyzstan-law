# Статья 10. Установление класса опасности отходов
1. Классы опасности отходов указываются в Классификаторе отходов.
2. Классы опасности отходов устанавливаются их производителями по согласованию с уполномоченным государственным органом в области охраны окружающей среды для всех образующихся отходов, если класс опасности отходов производства не указан в Классификаторе отходов.
Если производитель отходов не обеспечил установление класса опасности отходов, то их установление осуществляет юридическое лицо или индивидуальный предприниматель, к которым перешло право собственности на эти отходы.
3. Установление класса опасности отходов осуществляется на основании свойств, представляющих опасность для окружающей среды, здоровья граждан, имущества.
4. Установление класса опасности отходов осуществляется в порядке, установленном Кабинетом Министров Кыргызской Республики.
5. Выдача заключения о классе опасности отходов осуществляется по результатам определения опасных свойств отходов.
6. Класс опасности опасных отходов устанавливается исходя из наиболее высокого класса опасности, определенного по результатам исследования опасных свойств отходов.
