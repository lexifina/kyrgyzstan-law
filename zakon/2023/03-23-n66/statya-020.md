# Статья 20. Национальный логотип органической продукции
1. Национальный логотип органической продукции может использоваться при маркировке, презентации и рекламе органической продукции. Национальный логотип органической продукции утверждается уполномоченным государственным органом в сфере органического производства.
2. Уполномоченный государственный орган в сфере органического производства осуществляет мониторинг использования национального логотипа органической продукции.
3. Национальный логотип органической продукции может быть включен в этикетки или указания на этикетках органической продукции при условии, что:
1) данный логотип не используется для продукции "в переходном периоде на органическое производство";
2) используется для продукции, отмеченной как "органическая" или "органические продукты", но не используется для той продукции, которая отмечена как "изготовленные из органических продуктов".
4. Уполномоченный государственный орган в сфере органического производства вправе утвердить специальный национальный логотип, который будет использоваться для продукции, получившей подтверждение соответствия и качества через систему гарантийного участия (PGS).
5. Органическая импортная продукция, подпадающая под действие соглашения об эквивалентности, может быть повторно маркирована с нанесением национального логотипа органической продукции.
