# Статья 11-1. Выход из товарищества собственников жилья, обслуживающего несколько многоквартирных домов
1. Вопрос выхода одного многоквартирного дома из товарищества собственников жилья, обслуживающего несколько многоквартирных домов, выносится на общее собрание собственников многоквартирного дома, инициировавших выход из товарищества.
2. Решение о выходе из членства считается принятым, если за него проголосовало не менее 51 процента от общего числа собственников многоквартирного дома, инициировавших выход из товарищества.
3. В случае принятия решения о выходе протокол общего собрания передается в правление товарищества собственников жилья. Данный документ служит основанием для реорганизации товарищества собственников жилья.
4. После выхода из действующего товарищества собственников жилья собственники должны выбрать способ управления общим имуществом в течение трех месяцев в порядке, установленном законодательством Кыргызской Республики в сфере жилищных отношений.
