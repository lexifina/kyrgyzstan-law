# Статья 11. Направление гражданского персонала для участия в операциях по поддержанию мира и безопасности
1. Решение о направлении гражданского персонала для участия в миротворческой деятельности принимается Кабинетом Министров по предложению уполномоченного органа в сфере иностранных дел.
2. Уполномоченный орган в сфере иностранных дел на основании решения Кабинета Министров утверждает списки кандидатур, представляемых министерствами и ведомствами Кыргызской Республики, для участия гражданского персонала в миротворческих миссиях.
3. При этом уполномоченный орган в сфере иностранных дел определяет район действий указанного гражданского персонала, его задачи, срок пребывания и порядок замены.
