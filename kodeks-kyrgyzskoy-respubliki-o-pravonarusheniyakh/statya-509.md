# Статья 509. Возобновление приостановленного производства по делу о правонарушении
1. Приостановленное производство по делу о правонарушении возобновляется постановлением суда, уполномоченного органа после того, как отпали основания для приостановления.
2. О возобновлении производства по делу уведомляются лицо, привлекаемое к ответственности за правонарушение, и его законный представитель.
3. В случае обнаружения ранее неустановленного лица, совершившего правонарушение, по которому дело было приостановлено в соответствии с абзацем вторым части 2 статьи 508 настоящего Кодекса, постановление о возобновлении производства по делу выносится органом, составившим протокол, с последующим незамедлительным направлением дела в суд для решения вопроса о применении взыскания.
4. Сведения о возобновлении производства по делу о правонарушении вносятся в автоматизированную информационную систему (АИС) Единого реестра правонарушений.
