# Статья 130. Перемена адреса во время производства по делу
Лица, участвующие в деле, обязаны сообщить суду о перемене своего адреса во время производства по делу. При отсутствии такого сообщения извещение (повестка) посылается по последнему известному суду адресу и считается доставленным, хотя бы адресат по этому адресу более не проживает или не находится.
