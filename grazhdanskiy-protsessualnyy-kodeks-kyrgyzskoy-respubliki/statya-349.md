# Статья 349. Законная сила определений апелляционной инстанции
1. Определение суда апелляционной инстанции, вынесенное по частной жалобе (представлению), вступает в законную силу с момента его вынесения.
2. Определения, вынесенные судом апелляционной инстанции, не разрешающие апелляционную жалобу (представление) по существу, подлежат кассационному обжалованию в порядке, предусмотренном настоящим Кодексом.
