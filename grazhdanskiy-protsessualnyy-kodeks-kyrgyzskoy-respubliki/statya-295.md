# Статья 295. Решение суда по заявлению
1. Решение суда, которым гражданин признан ограниченно дееспособным, является основанием для назначения судом ограниченно дееспособному попечителя.
2. Решение суда, которым гражданин признан недееспособным, является основанием для назначения судом недееспособному опекуна.
