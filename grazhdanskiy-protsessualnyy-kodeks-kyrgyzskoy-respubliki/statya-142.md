Глава 14. Обеспечение иска
# Статья 142. Основания для обеспечения иска
1. По заявлению истца по делу третьего лица, заявляющего самостоятельные требования, ответчика, заявившего встречный иск, принятый судом к производству, суд может принять меры обеспечения иска. Обеспечение иска допускается только после принятия судом иска к производству на любой стадии рассмотрения дела, если непринятие таких мер может затруднить или сделать невозможным исполнение решения суда.
2. Рассмотрение вопросов о принятии мер по обеспечению иска, замене одного вида обеспечения иска другим, отмене обеспечения иска по заявлению стороны в третейском разбирательстве, осуществляемом постоянно действующим третейским судом, производится по правилам, предусмотренным настоящей главой.
