# Статья 165. Удаление свидетелей из зала судебного заседания
Явившиеся свидетели удаляются из зала судебного заседания. Председательствующий принимает меры к тому, чтобы допрошенные свидетели не общались с недопрошенными свидетелями, а в отношении свидетелей, допрашиваемых с использованием системы видеоконференцсвязи, принимает меры, исключающие участие таких свидетелей в судебном заседании указанным способом до начала их допроса.
