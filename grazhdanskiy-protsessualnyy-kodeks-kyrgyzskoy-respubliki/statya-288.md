# Статья 288. Решение суда по заявлению
1. Решение суда о признании гражданина безвестно отсутствующим является основанием для передачи его имущества лицу, с которым орган по защите детей заключает договор доверительного управления этим имуществом (при необходимости постоянного управления им).
2. Решение суда, которым гражданин объявлен умершим, является основанием для внесения органом записи актов гражданского состояния записи о смерти этого гражданина в книгу записей актов гражданского состояния.
