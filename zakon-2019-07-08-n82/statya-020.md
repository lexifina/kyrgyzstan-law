# Статья 20. Статистические регистры
1. Статистические регистры - это перечни статистических единиц и их характеристик, включая идентификаторы, необходимые для производства официальной статистики.
2. Национальный статистический комитет может создавать и вести статистические регистры для использования их исключительно в статистических целях.
