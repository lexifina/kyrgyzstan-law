# Статья 36. Невыполнение обязательств по предоставлению данных
Любой респондент, обязанный предоставлять данные, но который их намеренно не предоставляет, несмотря на полученное напоминание, или который намеренно предоставляет искаженные данные, может быть подвергнут штрафу в соответствии с Кодексом Кыргызской Республики о правонарушениях.
