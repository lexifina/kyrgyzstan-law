# Статья 35. Дистанционное, электронное голосование
1. При проведении референдума может применяться дистанционное, электронное голосование. Решение о проведении дистанционного, электронного голосования принимается при назначении референдума.
2. Дистанционное, электронное голосование предназначено для обеспечения реализации права на участие в референдуме граждан, включенных в список участников референдума, но не имеющих возможности голосовать на участке референдума по месту постоянной регистрации.
3. При проведении дистанционного, электронного голосования обеспечивается возможность реализации права граждан на участие в референдуме и формирования данных об итогах дистанционного, электронного голосования с гарантией сохранности волеизъявления участников референдума и соблюдения тайны голосования.
4. Порядок дистанционного, электронного голосования утверждается Центральной избирательной комиссией.
