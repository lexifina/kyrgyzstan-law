# Статья 31-1. Дистанционное, электронное голосование
1. При проведении выборов может быть применено дистанционное, электронное голосование. Решение о проведении дистанционного, электронного голосования принимается при назначении выборов.
2. Дистанционное, электронное голосование предназначено для обеспечения реализации активного избирательного права граждан, включенных в список избирателей, но не имеющих возможности голосовать на избирательном участке по месту постоянной регистрации.
3. При проведении дистанционного, электронного голосования обеспечивается возможность реализации активного избирательного права и формирования данных об итогах дистанционного, электронного голосования с учетом гарантии сохранности волеизъявления избирателей и соблюдения тайны голосования.
4. Порядок дистанционного, электронного голосования утверждается Центральной избирательной комиссией.
5. Не допускается дистанционное голосование вне своего избирательного участка в пределах одного избирательного округа, за исключением выборов Президента Кыргызской Республики, проводимых по единому общереспубликанскому избирательному округу.
