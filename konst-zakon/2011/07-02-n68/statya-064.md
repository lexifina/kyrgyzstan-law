# Статья 64. Определение и официальное опубликование результатов выборов депутатов Жогорку Кенеша
1. Центральная избирательная комиссия определяет результаты выборов по многомандатным избирательным округам в целом по республике.
2. Центральная избирательная комиссия на основании протоколов окружных избирательных комиссий путем суммирования содержащихся в них данных производит подсчет голосов избирателей, поданных по многомандатному избирательному округу за каждого кандидата.
3. Избранными по многомандатному избирательному округу признаются три кандидата, получившие наибольшее число голосов избирателей соответствующего избирательного округа, принявших участие в голосовании.
При равном числе полученных кандидатами голосов избранными по многомандатному избирательному округу считаются кандидаты, предоставившие раньше по дате и времени полный пакет документов для регистрации.
4. При распределении мандатов по соответствующему многомандатному избирательному округу не может быть выделено более двух мандатов для представителей одного пола.
5. При определении результатов выборов депутатов Жогорку Кенеша не менее 30 депутатских мандатов принадлежат депутатам одного пола.
6. Официальное опубликование в средствах массовой информации результатов выборов депутатов Жогорку Кенеша осуществляется Центральной избирательной комиссией в 2-недельный срок со дня определения результатов выборов.
