# Статья 2. Основные термины, применяемые в настоящем конституционном Законе
1) Национальный Совет - консультативно-совещательный рабочий орган Народного Курултая, который осуществляет свою деятельность на общественных началах;
2) секретариат - орган Народного Курултая, работающий на постоянной основе;
3) регламент - документ, утверждаемый Народным Курултаем, регулирующий порядок организации и проведения Народного Курултая;
4) делегат - представитель, избранный в Народный Курултай в установленном порядке;
5) положение - документ, определяющий порядок избрания делегатов Народного Курултая;
6) рабочая группа - группа, избранная из делегатов Народного Курултая, образованная для подготовки вопросов и внесения предложений по решению вопросов, рассматриваемых Народным Курултаем;
7) счетная комиссия - комиссия, избранная из делегатов Народного Курултая для подсчета голосов и подведения итогов голосования по рассматриваемым вопросам;
8) резолюция - решение, принятое Народным Курултаем по рассматриваемым им вопросам, имеющее рекомендательный характер.
