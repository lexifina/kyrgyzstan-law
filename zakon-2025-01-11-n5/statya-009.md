# Статья 9. Технические комитеты по стандартизации
1. Технические комитеты по стандартизации создаются национальным органом Кыргызской Республики по стандартизации с учетом следующих принципов:
1) добровольное участие;
2) равное представительство сторон;
3) соблюдение целей и задач стандартизации, установленных в статье 4 настоящего Закона;
4) открытость и доступность информации о техническом комитете по стандартизации.
2. Технические комитеты по стандартизации создаются для разработки национальных стандартов, сводов правил, межгосударственных стандартов (если разработка межгосударственных стандартов осуществляется Кыргызской Республикой), создания условий для участия в деятельности по стандартизации всех заинтересованных субъектов стандартизации.
3. Порядок создания, функционирования, мониторинга, оценки эффективности, ликвидации технических комитетов по стандартизации устанавливается национальным органом по стандартизации.
Организационное, информационно-аналитическое обеспечение деятельности технического комитета по стандартизации осуществляется организацией, на базе которой создан технический комитет.
Финансирование работ технических комитетов по стандартизации осуществляется на договорной основе с заинтересованными предприятиями и организациями за счет грантов, донорских средств и других источников.
