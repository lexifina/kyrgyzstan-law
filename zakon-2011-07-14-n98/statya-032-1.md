# Статья 32-1. Дистанционное, электронное голосование
1. При проведении выборов может быть применено дистанционное, электронное голосование. Решение о проведении дистанционного, электронного голосования принимается при назначении выборов.
2. Дистанционное, электронное голосование предназначено для обеспечения реализации активного избирательного права граждан, включенных в список избирателей, но не имеющих возможности голосовать на избирательном участке по месту постоянной регистрации и подавших заявление об участии в дистанционном, электронном голосовании.
3. При проведении дистанционного, электронного голосования обеспечивается возможность реализации активного избирательного права и формирования данных об итогах дистанционного, электронного голосования с учетом гарантии сохранности волеизъявления избирателей и соблюдения тайны голосования.
4. Для участия в дистанционном, электронном голосовании избиратель вправе не позднее 15 календарных дней до дня голосования обратиться с заявлением о намерении голосовать в дистанционной, электронной форме в соответствующую избирательную комиссию с прохождением биометрической идентификации либо через сервис "Кабинет избирателя" на государственном портале с прохождением авторизации в установленном законодательством порядке.
Избиратель, включенный в список участников дистанционного, электронного голосования, имеет право проголосовать только по электронному формату голосования.
5. Порядок дистанционного, электронного голосования утверждается Центральной избирательной комиссией.
