# Статья 8. Комиссия по этике
1. Комиссия по этике является независимым от Совета адвокатов органом Адвокатуры по рассмотрению вопросов, указанных в части 4 настоящей статьи.
Комиссия по этике избирается сроком на три года в составе:
- пяти представителей от Адвокатуры;
- двух представителей из числа юридических представителей;
- двух представителей, назначаемых Министерством юстиции Кыргызской Республики.
Адвокаты - члены комиссии по этике должны иметь стаж адвокатской деятельности не менее пяти лет и не иметь дисциплинарных взысканий за последние два года.
Условия, срок полномочий, порядок назначения, ротации и участия представителей Министерства юстиции Кыргызской Республики в работе комиссии по этике устанавливаются Министерством юстиции Кыргызской Республики самостоятельно. Представители Министерства юстиции Кыргызской Республики осуществляют участие в работе комиссии по этике исключительно в качестве членов комиссии по этике и не могут быть избраны на должности председателя или заместителя председателя комиссии по этике.
Комиссия по этике из своего состава избирает председателя и его заместителя открытым голосованием большинством голосов от общего числа членов комиссии по этике. Одно и то же лицо не может быть избрано членом комиссии по этике более двух сроков подряд.
2. Адвокаты - члены комиссии по этике могут совмещать работу в комиссии по этике с адвокатской деятельностью. Члены комиссии по этике не могут одновременно являться членами Совета адвокатов, ревизионной комиссии и правлений территориальных адвокатур.
3. Заседание комиссии по этике считается правомочным при участии более половины от общего числа членов комиссии.
4. К компетенции комиссии по этике относятся:
1) рассмотрение жалоб и обращений на действия (бездействие) адвоката;
2) дача разъяснений по вопросам применения Кодекса профессиональной этики адвокатов;
2-1) рассмотрение жалоб и обращений на действия (бездействие) юридических представителей;
2-2) дача разъяснений по вопросам, связанным с соблюдением стандартов профессионального поведения юридических представителей;
3) обобщение дисциплинарной практики;
4) иные вопросы в соответствии с настоящим Законом.
5. Комиссия по этике по результатам рассмотрения заявления, жалобы выносит решение.
6. Решение комиссии по этике принимается простым большинством голосов членов, участвующих в ее заседании, путем голосования. Протокол заседания комиссии по этике подписывается членами комиссии, принявшими участие в заседании.
7. В случае досрочного прекращения полномочий члена комиссии по этике его место занимает следующий по очереди кандидат, состоящий в резервном списке, утвержденном на Съезде адвокатов.
Резервный список членов комиссии по этике формируется на срок избрания комиссии по этике.
