# Статья 27. Страхование частного нотариуса
1. Частный нотариус обязан застраховать свою гражданско-правовую ответственность по обязательствам, возникающим вследствие причинения вреда в результате совершения нотариальных действий, путем заключения договора страхования. Нотариус не вправе выполнять свои обязанности без заключения договора страхования.
2. Минимальная страховая сумма устанавливается в 500-кратном размере расчетного показателя, установленного законом.
