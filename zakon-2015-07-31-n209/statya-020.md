# Статья 20. Предоставление информации для формирования базы данных
1. База данных содержит информацию о каждом заключенном договоре обязательного страхования, об объемах страховых премий, о страховых случаях и суммах страхового возмещения, а также об основных характеристиках застрахованных жилых помещений.
2. Порядок предоставления информации для формирования базы данных устанавливается Кабинетом Министров Кыргызской Республики.
