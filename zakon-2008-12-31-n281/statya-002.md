# Статья 2. Условия и порядок реструктуризации
1. Реструктуризации подлежат задолженности ОАО "Электрические станции" и ОАО "Национальная электрическая сеть Кыргызстана" по основным долгам, начисленным процентам, пени, финансовым и штрафным санкциям по налоговым, таможенным платежам и кредитам перед Государственным фондом развития экономики при Министерстве финансов Кыргызской Республики на общую сумму 3269,8 млн. сомов.
2. Погашение задолженностей по основным долгам ОАО "Электрические станции" и ОАО "Национальная электрическая сеть Кыргызстана" продлевается сроком на 10 лет с равномерным распределением задолженности по годам и начислением процентов по ставке 2% годовых. Погашение задолженности по основному долгу производится после истечения трех лет с момента вступления в силу настоящего Закона.
3. Порядок реструктуризации задолженности по ОАО "Электрические станции":
1) подлежит списанию задолженность по начисленным процентам, пени, финансовым и штрафным санкциям:
- по налогам - 587,4 млн. сомов;
- по таможенным платежам - 55,2 млн. сомов;
- по кредитам - 150,4 млн. сомов;
2) подлежит продлению срок уплаты задолженности по основному долгу в порядке, определенном пунктом 2 настоящей статьи:
- налоги - в сумме 824,2 млн. сомов;
- таможенные платежи - в сумме 563,5 млн. сомов.
4. Порядок реструктуризации задолженности по ОАО "Национальная электрическая сеть Кыргызстана":
1) подлежит списанию задолженность по начисленным процентам, пени, финансовым и штрафным санкциям:
- по налогам - 475,7 млн. сомов;
- по кредитам - 119,5 млн. сомов;
2) подлежит продлению срок уплаты задолженности по основному долгу в порядке, определенном пунктом 2 настоящей статьи:
- налоги - в сумме 493,9 млн. сомов.
5. Подлежит списанию электрораспредкомпаниями задолженность, имеющаяся по состоянию на 1 декабря 2008 года, по начисленной пени потребителям электроэнергии за несвоевременную оплату за электроэнергию.
6. В случае нарушения срока погашения задолженности по основному долгу за просроченные дни применяется ставка, равная учетной ставке Национального банка Кыргызской Республики, действующая на просроченный период.
7. В случае реорганизации основных поставщиков налоговое обязательство по погашению задолженности по основному налогу исполняется правопреемником.
