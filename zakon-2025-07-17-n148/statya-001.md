# Статья 1.
Внести в Семейный кодекс Кыргызской Республики (Ведомости Жогорку Кенеша Кыргызской Республики, 2004 г., № 1, ст.1) следующие изменения:
в пункте 3 статьи 63:
а) абзацы третий и четвертый изложить в следующей редакции:
"- по имени отца с добавлением слова "уулу" для детей мужского пола и слова "кызы" для детей женского пола или без добавления такового. В этих случаях отчество ребенку не присваивается;
- по имени дедушки без добавления окончания к нему, а также по желанию родителей может быть добавлено имя отца;";
б) дополнить абзацем пятым следующего содержания:
"- по имени дедушки с присоединением к нему слова "тегин", а также по желанию родителей может быть добавлено имя отца, либо имя отца с добавлением слова "уулу" для детей мужского пола, слова "кызы" для детей женского пола. По желанию родителей фамилия ребенку может присваиваться по имени предков до седьмого колена при наличии подтверждающих прямую родственную связь документов или их наличии в архивах уполномоченного государственного органа.".
