# Статья 4.
1. В случае отсутствия у лиц персональных идентификационных номеров подача заявления для государственной регистрации актов гражданского состояния осуществляется после присвоения таким лицам персональных идентификационных номеров в порядке, определяемом Правительством Кыргызской Республики.
2. Исключение из правила, установленного частью 1 настоящей статьи, представляет случай, когда при подаче заявления о государственной регистрации смерти у умершего лица отсутствует персональный идентификационный номер.
