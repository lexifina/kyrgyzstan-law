# Статья 120. Авансирование расходов взыскателем
1. В целях обеспечения совершения исполнительных действий взыскатель вправе произвести авансовый взнос судебному исполнителю в размере, достаточном для производства соответствующих расходов либо их части. По принятию авансового взноса судебным исполнителем выдается соответствующий документ об оплате авансового взноса.
2. Авансовый взнос подлежит отнесению к расходам по совершению исполнительных действий и по завершении исполнительных действий полностью возвращается взыскателю.
