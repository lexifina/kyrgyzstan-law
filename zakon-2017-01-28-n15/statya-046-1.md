# Статья 46-1. Ведение Реестра обязательств
1. В Реестре обязательств временно хранятся сведения по исполнительным документам, производство по которым окончено по основаниям, указанным в пунктах 4 и 7 части 1 статьи 114 настоящего Закона.
2. Уполномоченный государственный орган ведет Реестр обязательств, включающий сведения по исполнительным документам.
3. Наличие неисполненных обязательств по исполнительным документам, включенным в Реестр обязательств, проверяется государственными органами и иными организациями в режиме онлайн.
4. Государственные органы и иные организации в установленном порядке осуществляют оперативный обмен информацией с уполномоченным государственным органом по исполнительным документам, внесенным в Реестр обязательств.
