# Статья 142. Приостановление действия свидетельства частного судебного исполнителя
1. Приостановление действия свидетельства частного судебного исполнителя осуществляется решением уполномоченного государственного органа на основании представления дисциплинарной комиссии.
2. Действие свидетельства частного судебного исполнителя приостанавливается в случае привлечения частного судебного исполнителя в качестве обвиняемого по уголовному делу.
3. В решении уполномоченного государственного органа о приостановлении действия свидетельства частного судебного исполнителя должны быть указаны причины и сроки приостановления действия свидетельства. Действие свидетельства приостанавливается со дня получения частным судебным исполнителем решения уполномоченного государственного органа о приостановлении действия свидетельства. При устранении обстоятельств, послуживших причиной приостановления, уполномоченным государственным органом выносится решение о восстановлении действия свидетельства.
4. Приостановление действия свидетельства частного судебного исполнителя влечет запрет на осуществление деятельности в качестве частного судебного исполнителя и совершение исполнительных действий с момента включения данных в Единый реестр частных судебных исполнителей Кыргызской Республики.
5. Решение уполномоченного государственного органа о приостановлении действия свидетельства частного судебного исполнителя может быть обжаловано частным судебным исполнителем в судебном порядке.
6. Полномочия частного судебного исполнителя приостанавливаются по его заявлению в случае назначения (избрания) на государственную или муниципальную должность. После прекращения полномочий государственного или муниципального служащего данное лицо может возобновить исполнение полномочий частного судебного исполнителя.
