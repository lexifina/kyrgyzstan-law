# Статья 449. Особое мнение судьи суда кассационной инстанции
Судья кассационной инстанции, не согласный с решением большинства судей, обязан подписать решение суда без какой-либо оговорки и вправе письменно изложить особое мнение, которое приобщается к судебному акту, которое оглашению в зале судебного заседания не подлежит и является открытым для ознакомления сторонами по делу.
