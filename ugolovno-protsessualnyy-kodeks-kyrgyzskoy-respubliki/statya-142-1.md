# Статья 142-1. Выделение в отдельное производство материалов из уголовного дела
1. Следователь, судья, суд в случае если в ходе расследования уголовного дела или рассмотрения дела в суде становится известно о новом преступлении, совершенном другим лицом, не связанным с преступлением, вменяемым в вину обвиняемому по расследуемому делу, выделяет из уголовного дела материалы, необходимые для начала досудебного производства, а также возбуждения и производства следствия по уголовному делу о ставшем известным преступлении в порядке, предусмотренном статьями 148-151 настоящего Кодекса.
2. Выделение материалов из уголовного дела производится по постановлению следователя, судьи, суда, определению суда. К постановлению должен быть приложен перечень выделяемых в подлинниках или копиях материалов.
Заверению подлежат копии документов при наличии их подлинников. Если в материалах дела имеются только копии документов без представления подлинников, такие копии заверению не подлежат.
3. Следователь обязан незамедлительно вносить в Единый реестр преступлений сведения о выделении материалов из уголовного дела.";
