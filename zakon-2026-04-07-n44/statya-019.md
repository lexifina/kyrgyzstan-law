# Статья 19. Племенное предприятие по искусственному осеменению сельскохозяйственных животных
1. Племенное предприятие по искусственному осеменению сельскохозяйственных животных создается в порядке и на условиях, определяемых Кабинетом Министров.
2. Племенное предприятие осуществляет следующие функции:
1) содержит племенных животных - производителей, которые используются для получения семени;
2) проводит работы по получению, обработке, контролю качества и хранению семени;
3) реализует семя в пункты искусственного осеменения для проведения искусственного осеменения сельскохозяйственных животных.
