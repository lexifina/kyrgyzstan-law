# Статья 2.
Одобрить прогноз основных параметров бюджета Социального фонда Кыргызской Республики на 2011-2012 годы согласно приложению 1: прогноз по доходам на 2011 год - 18900,5 млн. сомов, на 2012 год 22636,6 млн. сомов, прогноз по расходам на 2011 год - 20867,3 млн. сомов, на 2012 год - 23952,7 млн. сомов, в том числе: Пенсионного фонда - прогноз по доходам на 2011 год - 17038,5 млн. сомов, на 2012 год - 20505,3 млн. сомов и прогноз по расходам на 2011 год - 19005,3 млн. сомов, на 2012 год - 21821,4 млн. сомов; Государственного накопительного пенсионного фонда - прогноз по доходам на 2011 год - 917,2 млн. сомов, на 2012 год - 1094,3 млн. сомов и прогноз по расходам на 2011 год - 917,2 млн. сомов, на 2012 год 1094,3 млн. сомов; Фонда обязательного медицинского страхования - прогноз по доходам на 2011 год - 837,5 млн. сомов, на 2012 год - 919,3 млн. сомов и прогноз по расходам на 2011 год - 837,5 млн. сомов, на 2012 год - 919,3 млн. сомов; Фонда оздоровления трудящихся - прогноз по доходам на 2011 год 107,3 млн. сомов, на 2012 год - 117,7 млн. сомов и прогноз по расходам на 2011 год - 107,3 млн. сомов, на 2012 год - 117,7 млн. сомов; прогноз дефицита бюджета Социального фонда Кыргызской Республики и Пенсионного фонда на 2011 год - 1966,8 млн. сомов, на 2012 год - 1316,0 млн. сомов. Прогнозные параметры бюджета Социального фонда Кыргызской Республики, одобренные на 2011-2012 годы, подлежат уточнению при их принятии в каждом конкретном периоде.
