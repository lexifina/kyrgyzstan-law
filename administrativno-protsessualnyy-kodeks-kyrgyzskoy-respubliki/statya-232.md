# Статья 232. Отмена решения с прекращением производства по делу или оставлением иска без рассмотрения
Решение суда первой инстанции подлежит отмене в апелляционном порядке с прекращением производства по делу или оставлением заявления без рассмотрения по основаниям, указанным в статьях 186, 188 и 189 настоящего Кодекса.
