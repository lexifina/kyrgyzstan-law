# Статья 238. Разъяснение решения суда апелляционной инстанции
1. Суд апелляционной инстанции в порядке, установленном статьей 179 настоящего Кодекса, может разъяснить свое решение.
2. На определение суда по вопросу о разъяснении решения может быть подана частная жалоба (представление) в кассационную инстанцию.
