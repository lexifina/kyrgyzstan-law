# Статья 33. Бюллетень для голосования на референдуме
1. Для участия в референдуме участник референдума получает бюллетень для голосования, являющийся документом строгой отчетности, степень защиты которого определяется Центральной избирательной комиссией.
2. В бюллетене для голосования точно воспроизводится текст вынесенного на референдум вопроса и указываются варианты волеизъявления голосующего словами «За», «Против», под которыми помещаются пустые квадраты. В случае вынесения на референдум альтернативных вариантов вопросов в бюллетене для голосования также указывается вариант волеизъявления «Против всех вариантов». Справа от каждого варианта помещается пустой квадрат, при этом участник референдума имеет право выбрать только один вариант. В случае вынесения на референдум нескольких вопросов они включаются в один бюллетень по отдельности. В бюллетене для голосования также указывается вариант волеизъявления «Против всех вариантов» либо для каждого вопроса референдума бюллетень изготавливается отдельно. Напротив каждого вопроса указывается вариант волеизъявления голосующего словами «За» и «Против», справа от которых помещаются пустые квадраты.
3. Форма и текст бюллетеня для голосования утверждаются Центральной избирательной комиссией не позднее чем за 20 календарных дней до дня проведения референдума. Текст бюллетеня для голосования размещается только на одной его стороне.
4. Участки референдума оснащаются специальными трафаретами для самостоятельного заполнения участниками референдума с инвалидностью бюллетеней для голосования, в том числе бюллетенями с применением шрифта Брайля.
5. Помещение, в котором находится специальный сейф (шкаф), где хранятся списки участников референдума и другие документы, печать соответствующей избирательной комиссии, опечатывается и передается под охрану органов внутренних дел. При этом в день голосования сейф (шкаф) должен находиться внутри помещения участка референдума, где осуществляется голосование.
6. Запрещается выносить из помещений избирательных комиссий, а также копировать и распространять бюллетени для голосования в нарушение требований настоящего конституционного Закона.
