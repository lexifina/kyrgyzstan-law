# Статья 321-1. Нарушение требований к центрам технического обслуживания
Нарушение требований налогового законодательства, предъявляемых к центрам технического обслуживания, -
влечет наложение штрафа на физических лиц в размере 200 расчетных показателей, на юридических лиц - 650 расчетных показателей.
