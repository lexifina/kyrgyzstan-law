# Статья 308-1. Нарушение требования по ведению реестра налогового агента по наемным работникам
Нарушение требования по ведению реестра налогового агента по наемным работникам -
влечет наложение штрафа на физических лиц в размере 30 расчетных показателей, на юридических лиц - 65 расчетных показателей.
