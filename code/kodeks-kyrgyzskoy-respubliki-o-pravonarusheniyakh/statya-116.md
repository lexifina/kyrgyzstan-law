# Статья 116. Повреждение водохозяйственных сооружений
Повреждение водохозяйственного сооружения либо устройства, разрушение коллекторно-дренажной системы, а равно умышленное либо неосторожное нарушение правил их эксплуатации –
влекут наложение штрафа на физических лиц в размере 200 расчетных показателей, на юридических лиц – 650 расчетных показателей.
