# Статья 207. Нарушение требований экологической безопасности при осуществлении операций с биологически активными веществами и предметами биотехнологий
Нарушение требований экологической безопасности при производстве либо обращении с микроорганизмами, другими биологически активными веществами или предметами биотехнологий –
влечет наложение штрафа на физических лиц в размере 125 расчетных показателей, на юридических лиц – 350 расчетных показателей.
