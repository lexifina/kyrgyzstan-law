# Статья 200-2. Нарушение требований по уплате сбора за проезд по автомобильным дорогам общего пользования
Неуплата установленного сбора за проезд по автомобильным дорогам общего пользования -
влечет наложение штрафа на физических лиц в размере 200 расчетных показателей, на юридических лиц - 650 расчетных показателей.
