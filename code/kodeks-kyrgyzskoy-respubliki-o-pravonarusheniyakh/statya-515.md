# Статья 515. Оценка доказательства
Суд, уполномоченный орган оценивает доказательства по своему внутреннему убеждению, основанному на всестороннем, полном и объективном исследовании всех обстоятельств дела в их совокупности. Никакие доказательства не могут иметь заранее установленной юридической силы.
