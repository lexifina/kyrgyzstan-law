# Статья 564. Окончание производства по исполнению постановления о наложении штрафа
Постановление о наложении штрафа, по которому взыскание штрафа произведено полностью, с отметкой об исполнении возвращается уполномоченному органу, вынесшему постановление, а в случае наложения штрафа судом – органу, составившему протокол о правонарушении.
