# Статья 455. Центральная комиссия по проведению выборов и референдумов Кыргызской Республики, избирательные комиссии
Центральная комиссия по проведению выборов и референдумов Кыргызской Республики, избирательные комиссии рассматривают дела о правонарушениях и налагают взыскания, предусмотренные статьями 60–62, 64–69, частью 2 статьи 142 настоящего Кодекса.
