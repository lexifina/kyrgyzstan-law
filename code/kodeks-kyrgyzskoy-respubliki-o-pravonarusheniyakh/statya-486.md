# Статья 486. Уполномоченный орган, осуществляющий функции по исполнению исполнительных документов
Уполномоченный орган, осуществляющий функции по исполнению исполнительных документов рассматривает дела о правонарушениях и налагает взыскания, предусмотренные статьями 443, 443-1и 444 настоящего Кодекса.
