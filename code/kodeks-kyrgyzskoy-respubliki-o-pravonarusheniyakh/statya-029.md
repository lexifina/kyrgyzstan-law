# Статья 29. Предупреждение
Предупреждение выносится уполномоченным органом в письменной форме и имеет целью недопущение совершения подобных правонарушений в будущем. Предупреждение может применяться при совершении правонарушений, не повлекших вредных последствий, в случаях, предусмотренных Особенной частью настоящего Кодекса.
