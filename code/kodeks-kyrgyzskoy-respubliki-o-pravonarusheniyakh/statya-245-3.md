# Статья 245-3. Пользование природными ресурсами без разрешения
Пользование природными ресурсами без разрешения, невнесение платежей за выбросы (сбросы) загрязняющих веществ, размещение отходов, кроме случаев наличия лицензии на право пользования, а также без разрешения государственных органов охраны окружающей среды -
влечет наложение штрафа на физических лиц в размере 100 расчетных показателей, на юридических лиц - 280 расчетных показателей.
