# Статья 224. Нарушение требований безопасного ведения работ при обращении с радиоактивными отходами
Нарушение требований безопасного ведения работ при обращении с радиоактивными отходами –
влечет наложение штрафа на физических лиц в размере 125 расчетных показателей, на юридических лиц – 350 расчетных показателей.
