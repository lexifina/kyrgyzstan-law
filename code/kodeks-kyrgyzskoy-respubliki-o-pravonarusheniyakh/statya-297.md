# Статья 297. Нарушение установленных законодательством требований представления для апробирования и клеймения ювелирных и других изделий из драгоценных металлов, ввезенных из стран, не входящих в Евразийский экономический союз
Нарушение требований представления для апробирования и клеймения ювелирных и других изделий из драгоценных металлов, ввезенных из стран, не входящих в Евразийский экономический союз, –
влечет наложение штрафа на физических лиц в размере 125 расчетных показателей, на юридических лиц – 350 расчетных показателей.
