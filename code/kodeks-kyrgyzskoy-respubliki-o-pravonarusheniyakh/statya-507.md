# Статья 507. Особенности ведения производства по делам о правонарушениях уполномоченными органами, владеющими базами данных
1. При выявлении правонарушений уполномоченными органами, владеющими базами данных, в которых содержатся сведения о правонарушителе, необходимые для фиксации факта правонарушения, а также для составления протокола по делу о правонарушении, уполномоченный орган, выявивший нарушение, может составить протокол по делу о правонарушении без участия правонарушителя.
Для применения настоящей статьи обстоятельства должны соответствовать следующим критериям:
1) база данных уполномоченного органа содержит сведения о правонарушителе (фамилия, имя, отчество (если имеется) физического лица, наименование юридического лица);
2) база данных уполномоченного органа содержит сведения о местонахождении правонарушителя (месте жительства, месте регистрации, местонахождении, месте ведения деятельности);
3) факт правонарушения возможно выявить без участия правонарушителя.
2. При выявлении факта правонарушения в соответствии с требованиями настоящей статьи уполномоченный орган составляет протокол без участия правонарушителя и направляет его по почте с обратным уведомлением вместе с извещением о назначении времени и места рассмотрения дела по адресу, по которому располагается уполномоченный орган.
В таких случаях срок рассмотрения дела устанавливается не более 25 календарных дней с момента составления протокола.
3. При применении настоящей статьи дела о правонарушениях рассматриваются исключительно в составе комиссии уполномоченного органа.
