# Статья 344. Нарушение законодательства об обязательном страховании страховыми организациями
Нарушение или неисполнение страховыми организациями требований законодательства об отдельных видах обязательного страхования –
влечет наложение штрафа на юридических лиц в размере 280 расчетных показателей.
