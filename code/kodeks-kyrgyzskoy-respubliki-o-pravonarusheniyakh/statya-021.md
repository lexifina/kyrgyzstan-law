# Статья 21. Обстоятельства, исключающие противоправность правонарушения
Обстоятельствами, исключающими противоправность правонарушения, являются необходимая оборона, крайняя необходимость, причинение вреда при задержании лица, совершившего противоправное деяние, физическое или психическое принуждение, выполнение законного приказа или распоряжения.
