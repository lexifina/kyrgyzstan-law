# Статья 413. Нарушение установленных охранных зон для телекоммуникационных сетей
Нарушение охранных зон для телекоммуникационных сетей, установленных в соответствии с земельным и градостроительным законодательством, -
влечет наложение штрафа на физических лиц в размере 30 расчетных показателей, на юридических лиц - 130 расчетных показателей.
