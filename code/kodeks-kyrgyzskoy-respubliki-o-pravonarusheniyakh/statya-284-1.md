# Статья 284-1. Осуществление медицинской и фармацевтической деятельности без лицензии
Осуществление медицинской и фармацевтической деятельности без лицензии (разрешения), обязательность получения которой предусмотрена законом, -
влечет наложение штрафа на физических лиц в размере 500 расчетных показателей, на юридических лиц - 1000 расчетных показателей.
