# Статья 111. Самовольное использование элементов общего имущества многоквартирных жилых домов
Самовольное использование элементов общего имущества многоквартирных жилых домов: подвалов, полуподвалов, сушильных помещений, чердаков, крыши, лестничных клеток, лифтов, подъездов, инженерного оборудования, придомовых территорий, являющихся совместной собственностью собственников квартир, –
влечет наложение штрафа на физических лиц в размере 10 расчетных показателей с приведением в первоначальное положение.
