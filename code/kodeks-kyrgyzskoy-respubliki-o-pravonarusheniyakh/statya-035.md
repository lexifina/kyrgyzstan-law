# Статья 35. Пеня
1. Пеня является денежной платой, которая исчисляется в процентах от суммы несвоевременной уплаты штрафа за каждый день просрочки уплаты в размере, равном 1 проценту.
2. Размер пени начисляется в расчете 100 процентов от суммы наложенного размера штрафа по истечении срока для начисления пени.
Примечание. Пеня не начисляется на сумму наложенного размера штрафа за правонарушения, предусмотренные статьями 177-180, 182-200 настоящего Кодекса.
