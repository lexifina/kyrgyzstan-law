# Статья 337. Отсутствие учета или отчетности о доходах по операциям с ценными бумагами
Отсутствие учета или отчетности о доходах по операциям с ценными бумагами либо ведение такой отчетности с нарушением установленного порядка –
влечет наложение штрафа на физических лиц в размере 30 расчетных показателей, на юридических лиц – 130 расчетных показателей.
