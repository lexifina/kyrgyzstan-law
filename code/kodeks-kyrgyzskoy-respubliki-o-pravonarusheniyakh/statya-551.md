# Статья 551. Рассмотрение судьей районного (городского) суда жалобы на постановления уполномоченного органа по делу о правонарушении
1. По итогам рассмотрения жалобы на постановление уполномоченного органа по делу о правонарушении судья районного (городского) суда принимает одно из следующих решений:
1) об оставлении постановления по делу о правонарушении без изменения, а жалобы – без удовлетворения;
2) об отмене постановления по делу о правонарушении и прекращении производства по делу о правонарушении.
2. Решение по результатам рассмотрения жалобы выносится в виде постановления и вступает в законную силу немедленно.
3. Копия постановления по жалобе на постановление по делу о правонарушении в течение трех дней высылается лицу, в отношении которого оно вынесено, и пострадавшему.
