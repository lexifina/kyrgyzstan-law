# Статья 283. Изготовление, сбыт и хранение спиртных напитков домашней выработки
Изготовление, сбыт либо хранение с целью сбыта спиртных напитков домашней выработки, изготовление или хранение без цели сбыта средств производства для их выработки -
влекут наложение штрафа на физических лиц в размере 45 расчетных показателей, на юридических лиц - 130 расчетных показателей.
