# Статья 21. Валюта обязательства по уплате неналогового дохода
1. Обязательство по уплате неналогового дохода исполняется в национальной валюте Кыргызской Республики - сомах, кроме случаев, установленных законодательством Кыргызской Республики.
2. При исчислении обязательства по уплате неналогового дохода допускается округление суммы обязательства до единиц сомов.
