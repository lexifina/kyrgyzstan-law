# Статья 1. Оплата за электроэнергию согласно установленным нормам
потребления
Оплата за электроэнергию, потребляемую для бытовых нужд населением города Каракуль в размере до 150 кВт/ч, осуществляется по себестоимости электроэнергии, вырабатываемой Токтогульской ГЭС, с учетом норм потребления, установленных Правительством Кыргызской Республики.
