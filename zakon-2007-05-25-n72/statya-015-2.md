# Статья 15-2. База данных учета проверок
1. Уполномоченные органы ведут электронную базу данных субъектов проверок.
2. База данных субъектов проверок подразделяется на информационную и контрольную части.
3. Контрольная часть содержит информацию по результатам проверок, о субъектах и объектах проверок и доступна исключительно уполномоченным органам.
4. Порядок организации и ведения базы данных субъектов проверок определяется Кабинетом Министров Кыргызской Республики.
5. Проведение плановых проверок, информация о которых отсутствует в электронной базе данных, не допускается.
