# Статья 10. Основания прекращения оперативно-розыскных мероприятий
1. Оперативно-розыскные мероприятия прекращаются:
1) при выполнении задач, для решения которых их проведение было предусмотрено;
2) в случае установления обстоятельств, свидетельствующих об объективной возможности решения поставленных задач;
3) при выявлении обстоятельств, исключающих привлечение проверяемого лица к ответственности по основаниям, предусмотренным уголовным законодательством Кыргызской Республики;
4) по истечении сроков проведения оперативно-розыскных мероприятий по специальным следственным действиям.
2. Организация и тактика проведения оперативно-розыскных мероприятий определяются решениями руководителей уполномоченных органов.
